# VisionCart - Visual Shopping Chrome Extension

AI-powered visual search assistant for e-commerce websites.

## Features
- **Hover Search Button**: Automatically floats a "VisionCart" lens badge whenever you hover over any product photo on shopping websites (Amazon, Meesho, Flipkart, Myntra, Ajio, Zara, Shein, eBay, etc.).
- **Right-Click Context Menu**: Right-click ANY image on any webpage and select *"Find product with VisionCart"*.
- **In-Page Slide-In Drawer**: Slides in directly on the page without navigating away.
- **Gemini Vision AI Attribute Breakdown**: Identifies product type, category, fabric/material, colors, silhouette, and style.
- **Multi-Product Item Detection**: If an outfit photo has multiple items (e.g. hoodie, pants, sneakers, watch), click any item to isolate search!
- **"Search Everywhere" Store Launchers**: Direct 1-click deep search into Meesho, Amazon, Flipkart, Myntra, Ajio, and Google Shopping.
- **Visual Similarity Ranking**: Ranks catalog products into Best Matches (75-100%), Similar (60-74%), and Alternatives (<60%).

## How to Install in Google Chrome, Edge, or Brave:
1. Open your browser and navigate to: `chrome://extensions` (or `edge://extensions` or `brave://extensions`).
2. Toggle on **Developer mode** in the top-right corner.
3. Click the **"Load unpacked"** button in the top-left corner.
4. Select this extracted `extension` folder.
5. VisionCart is now active! Pin it to your toolbar and visit any e-commerce website (e.g., amazon.in, meesho.com, flipkart.com) to search products visually.
